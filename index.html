Setup guide ▼

ⓘ The connection test and form lookup require the Cloudflare Worker proxy — KoboToolbox does not allow direct browser requests from any origin. The ZIP export itself runs entirely client-side once the form is connected.
1
Go to workers.cloudflare.com and sign up for a free account.
2
Click Create Worker and delete all the default code in the editor.
3
Download and open kobo_cors_proxy_worker.js, copy all its contents, and paste into the Cloudflare editor.
4
Click Save & Deploy. Copy your permanent Worker URL:
https://kobo-proxy.YOUR-NAME.workers.dev
5
In the Connection section, paste your Worker URL into the Cloudflare Proxy field (a default is pre-filled — replace it with your own), then click Connect.
ⓘ The Worker only forwards requests to eu.kobotoolbox.org. Your API token is never stored or logged.
ⓘ The edit tool uses KoboToolbox's API directly — the Cloudflare Worker proxy is required to relay requests from your browser to KoboToolbox.
